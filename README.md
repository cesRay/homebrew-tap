# cesRay Homebrew tap

```bash
brew tap cesRay/tap
brew trust --formula cesray/tap/visor   # Homebrew 7+ only loads trusted third-party formulae
brew install visor
```

| Formula | Description |
|---------|-------------|
| [visor](https://github.com/cesRay/visor) | A ranger-style terminal file navigator with content and filename search |

The formula source lives in [cesRay/visor](https://github.com/cesRay/visor/tree/main/packaging/homebrew). Update it there, then copy it to `Formula/` here.
